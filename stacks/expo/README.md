# Stack Expo — anunciado

Un stack para aplicaciones móviles con Expo y React Native. **Todavía no existe**: esta carpeta sólo lo anuncia, y
`install.sh` no lo ofrece mientras no tenga su `stack.json`.

Cuando llegue, será como los demás: un `stack.json` con los archivos que aporta y el rango del núcleo con el que es
compatible, sus reglas (`.ai/RULES.md`), sus plantillas y su `bin/verify.sh`, sin depender de ningún otro stack.
